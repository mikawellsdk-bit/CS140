Question answers

Normal flow in HTML

The default way elements are arranged on a page. Block elements appear on new lines; inline elements appear within the same line.

Float and clear:

float moves an element left or right so text wraps around it. clear prevents elements from wrapping around floats.

Relative, absolute, and fixed:

  • relative: Moves an element from its normal position.
  • absolute: Positions an element relative to its nearest positioned ancestor.
  • fixed: Keeps an element in the same position on the screen while scrolling.

Mobile navigation buttons:

Use CSS Flexbox, media queries, large buttons, readable text, and spacing to make navigation mobile-friendly.
