box model

Block vs. inline tags: Block tags start on a new line, while inline tags stay within the same line of text.

Margin, border, and padding: Margin is space outside an element, border is its outline, and padding is space inside the border around the content.

CSS measurement units: Common CSS units include px, %, em, rem, vw, vh, pt, cm, and in.

Figure tag: The figure tag is used to group content such as images, charts, or diagrams, often with a caption.
