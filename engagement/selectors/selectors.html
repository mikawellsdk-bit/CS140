  2. What is the difference between an ID and a Class?
    • An ID is used to identify one specific element and is written with #, while a class can be used for multiple elements and is written with .. For example, #header selects an ID and .button selects a class.
  3. What is the difference between a SPAN tag and a DIV tag?

  4. What is the difference between a DIV tag and a HEADER, MAIN, or FOOTER?
    • A div is a general container without semantic meaning. header, main, and footer are semantic elements that describe the purpose of the content, such as the top section, main content, and bottom section of a webpage.
