Questions and Answers

1. What kind of photos are good to encode using JPEG?

JPEG is good for photographs with many colors and details.

2. What kind of photos are good to encode using GIF?

GIF is good for simple pictures, logos, icons, and animations.

3. What is unique about the PNG format?

PNG keeps good image quality and can have a transparent background.

4. How do you resize your photo?

You can resize a photo using photo-editing software.

5. Why should you resize photos using photo-editing software instead of CSS?

Photo-editing software makes the file smaller, so the website loads faster. CSS only changes how large the picture looks.
