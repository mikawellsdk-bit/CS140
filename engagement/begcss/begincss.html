CSS

  1. Explain the difference between inline, embedded, and external CSS
    • Inline CSS is written inside an HTML tag, embedded CSS is written in the style section of a page, and external CSS is stored in a separate file.
  2. Explain why you should only use external CSS
    • External CSS should be used because it keeps code organized, reusable, and easier to update
  3. What is a selector used for?
    • A selector is used to choose which HTML elements CSS styles will apply to.
