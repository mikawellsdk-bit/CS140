Notes

  • table:starts the table.
  • border="1" adds visible borders around the cells for practice
  • tr:creates a row
  • th:creates a heading cell"
  • td:creates a regular cell containing information.
  • th colspan="6" tells the browser that this one cell should stretch across six columns.
  • thead: groups the column headings.
  • tbody: groups the main information.
  • tfoot: groups summary information, such as a total.
  • The : caption: tag gives the table a title.
  • scope="col" means the heading describes a column.
  • scope="row" means the heading describes a row
