EG Questions

  • Action: Tells the form where to send information.
  • Method: Tells the form how to send information.
  • POST vs GET:
    • GET = Information shows in the URL.
    • POST = Information is sent in the background.
  • Preset value vs placeholder:
    • Text box: value fills in text. Placeholder gives a hint.
    • Textarea: Text goes between the opening and closing tags. Placeholder gives a hint.
    • Select box: Use selected to choose a default option.
    • Checkbox: Use checked to select it by default.
    • Radio button: Use checked to select it by default.
  • HTML5 added input types:
    • email
    • url
    • tel
    • search
    • number
    • range
    • date
    • month
    • week
    • time
    • datetime-local
    • color
