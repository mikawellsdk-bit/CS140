off topic but lets talk Links!🔗

A relative link is a link that connects one page to another page or file within the same website. Instead of using the full website address, it uses a shorter path based on the current page’s location. Relative links make it easier to organize a website and move between its pages. An absolute link is a link that uses the full web address (URL) to direct you to a specific webpage or file. It includes the protocol (such as https://), the domain name, and the page’s location. Absolute links can take you to pages on the same website or a completely different website.
